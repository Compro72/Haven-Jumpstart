# Jumpstart Haven Project
A project made for Jumpstart Haven!
You are a basketball who can jump around, follow arrows and explore secrets in a platformer style game.

## Demo Link
You can find the demo link [here](https://compro72.itch.io/jumpstart-haven-guelphwaterloo).

## Tech Stack
The [Godot](https://godotengine.org) Game Engine was used to create this game!
